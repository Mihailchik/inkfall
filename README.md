# Вода и свет

Небольшой статический сайт из двух интерактивных сцен. Ни сборки, ни зависимостей:
каждая страница — один самодостаточный HTML-файл.

| Файл | Что это |
| --- | --- |
| `index.html` | Витрина со ссылками на сцены |
| `tush-i-voda.html` | Гидродинамика на GPU: тушь расплывается по воде за курсором |
| `yantarnaya-tumannost.html` | Процедурная туманность, закручивается за курсором |

## Локальный запуск

Файлы открываются двойным кликом, но микрофон в сцене с тушью так работать не будет:
браузер не даёт доступ к устройствам страницам с адресом `file://`. Для полной
функциональности нужен локальный сервер:

```bash
python3 -m http.server 8777 --bind 127.0.0.1
```

Дальше `http://localhost:8777`. Остановить: `pkill -f "http.server 8777"`.

## Деплой

Каталог статический, подходит любой хостинг. Корень публикации — корень репозитория.

```bash
# Vercel
npx vercel deploy --prod

# Netlify
npx netlify deploy --prod --dir .

# Cloudflare Pages
npx wrangler pages deploy .
```

Для GitHub Pages достаточно включить Pages в настройках репозитория и выбрать ветку `main`, папка `/` (корень).

Сервер должен отдавать `.html` как `text/html; charset=utf-8`. Все страницы объявляют
кодировку сами, так что даже сервер без настройки покажет текст верно.

### После появления домена

Один раз выполнить, подставив свой адрес:

```bash
node set-domain.mjs https://ваш-домен
```

Скрипт пропишет во все страницы канонический адрес, `og:url` и `og:image`,
соберёт `sitemap.xml` и добавит ссылку на него в `robots.txt`.

### Картинка предпросмотра

`og.jpg` снят с самой сцены. Пересобрать её можно так:

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new \
  --enable-unsafe-swiftshader --window-size=1200,630 --virtual-time-budget=6200 \
  --screenshot=og-raw.png "http://localhost:8777/tush-i-voda.html?bare=1"
ffmpeg -y -i og-raw.png -q:v 3 og.jpg && rm og-raw.png
```

Параметр `?bare=1` прячет весь интерфейс, так что в кадр попадает только сцена.
Время в `--virtual-time-budget` задаёт, насколько успеет расплыться тушь.

### Аналитика

Подключена Vercel Web Analytics: только счётчик просмотров, без куки и личных
данных. На локальном адресе не грузится. Включается в панели Vercel, в разделе
Analytics. Если хостинг другой, замените строку в `<head>` на свой счётчик,
например Plausible или GoatCounter.

## Требования браузера

Обеим сценам нужен WebGL. «Тушь и вода» требует WebGL2 с плавающими текстурами и
показывает понятное сообщение, если их нет. Запись видео работает через MediaRecorder:
Chrome отдаёт MP4, остальные браузеры — WebM.

Конвертация WebM в MP4:

```bash
ffmpeg -i вход.webm -c:v libx264 -crf 18 -pix_fmt yuv420p выход.mp4
```
